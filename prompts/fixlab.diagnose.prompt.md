Read the FixLab profile and the completed intake. Trace the smallest continuous
code and data path that explains the symptom. Inspect relevant history,
configuration, logs, and tests. Distinguish code defects from data, permission,
cache, deployment, or configuration causes. Do not change code until the root
cause and affected component are supported by evidence.
